# 🔗 BitTree — Linktree Clone

BitTree is a simple Linktree-inspired web application where you can create your own personalized page and keep all your important links in one place.

I built this project to practice **Next.js, MongoDB, Tailwind CSS, API routes, and deployment with Vercel**.

🌐 **Live Demo:** https://linktree-clone-plum-phi.vercel.app/

---

## ✨ Features

- 🔗 Create your own personalized BitTree page
- 👤 Choose a unique handle for your page
- ➕ Add multiple links
- 🖼️ Add a profile picture
- 📝 Add a short description
- 🌐 Get a public URL based on your handle
- 💾 Store BitTree data using MongoDB Atlas
- 📋 View your previously claimed links
- 📱 Responsive design for desktop, tablet, and mobile
- ☁️ Deployed using Vercel

---

## 🛠️ Tech Stack

- **Next.js** — React framework used to build the application
- **JavaScript** — Main programming language
- **Tailwind CSS** — Styling and responsive design
- **MongoDB Atlas** — Database for storing BitTree information
- **Mongoose** — MongoDB object modeling
- **Vercel** — Deployment and hosting

---

## 🚀 How It Works

Creating a BitTree is simple:

1. Enter the handle you want.
2. Add your links.
3. Add a profile picture URL.
4. Add a description.
5. Click **Create your BitTree**.
6. Your information is stored in MongoDB.
7. Your public BitTree page becomes available at:

https://your-domain.com/your-handle
